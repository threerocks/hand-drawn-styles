# #1.2 亲子投稿蜡笔故事卡验证记录

## 目标与视觉真源

- 用户在 2026-08-03 再次指定的主视觉锚点:`../../assets/style-1.2/anchor-family.png`。新附件与仓库锚点的文件字节不同,但解码像素完全一致;因此视觉真源无需换图。
- 目标不是复刻锚点里的家庭成员,而是稳定继承线条、五官、人物比例、蜡笔填色、留白和明亮白底。
- 配方与调用合同:`STYLES.md` #1.2 + `scripts/render_prompt.py`。

判定维度:

- 五官:小竖椭圆黑点眼、小折线鼻、随情绪变化的极短歪线嘴、珊瑚红乱涂圆腮红;不得复制同一张笑脸,也不得出现眼白、大虹膜、睫毛或商业萌脸。
- 比例:成人与孩子高矮清楚,身体简化但不是 Q 版巨头、火柴四肢或写实人体。
- 线条:细到中等粗黑色歪线,压力不匀、轻微断线与重复描,不得统一粗黑卡通描边。
- 填色:随机蜡笔短笔画、大片露白、自然越界,不得把露白与越界按固定比例平均分配。
- 构图:主体在中下部,上方大留白,只保留讲清动作所需的极少道具。
- 泛化:换成非家庭身份后仍保持同一视觉语言,不复制锚点人物与站位。
- 人物灵魂:同页人物的头型、肩宽、躯干歪斜、五官高低和涂色缺陷必须各不相同,不能用同一骨架批量换装。

## 入库结论

- 新增稳定身份 `1.2` / `family-crayon-card` / `parent-child-crayon` / `submission-crayon`。
