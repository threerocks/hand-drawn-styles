## 目标和边界

本轮把十张外部参考图共有的视觉机制抽象为原创画风 `warm-yellow-ink-story`。参考图只用于观察和维护者验证，不复制进仓库，不作为公开资产分发。最终配方不得包含作者名、账号名、水印、固定角色、原作构图或原作文案。

生成模型存在随机性，因此本项目不承诺逐像素复刻或“永不漂移”。生产合同的目标是：每次请求都携带通过像素哈希校验的原创画风锚点；配方锁定视觉语法；调用包固定模型快照要求、输入和验收条件；任何硬性条件失败时停止交付。

工作区已经存在未提交的 `benchmarks/style-19-roundhead-redline/`。本轮使用编号 20，避免覆盖或占用那组用户工作。

## 已观察到的视觉机制

### 形体和五官

- 人物使用圆方头、短颈或无颈、短粗躯干和短腿。头约占人物总高度的三分之一至二分之一，但不做三维 Q 版球头。
- 五官压缩为小黑点或短竖线眼、极短弯线嘴、可省略的小鼻点，以及两团低压珊瑚粉腮红。表情主要依靠头部倾斜、嘴线和身体动作表达。
- 黑发是实心或密集干笔排线形成的大色块，内部保留顺着发流的白色断缝和少量飞丝。裤子也使用可见方向的黑色干性排线，但不能变成平滑纯黑矢量块。
- 手脚极简。手用小钩或 2–4 根短线；脚是圆钝鞋袜块。动作必须一眼可读，但关节和解剖保持笨拙、松弛。

### 线和媒材

- 轮廓是黑色或极深暖灰的钢笔、铅笔或干性墨线。线宽轻微变化，压力不均，偶尔断开、回描和出头；不是统一粗黑描边。
- 黄色衣物接近平涂，但仍能看见轻微纸纹和不均匀的干性颜料覆盖。黑色头发和裤子必须保留方向性笔触。
- 纸面是平铺的暖白绘图纸气质，只允许细微、均匀的纤维感；不出现桌面、折痕、卷边、摄影阴影、做旧暗角或强微距纸纹。

### 配色和构图

- 核心色板固定为暖白、墨黑、暖芥末黄和极少珊瑚粉。叙事必需时可增加一个面积很小的红色或绿色道具，但默认不增加第五主色。
- 黄色用于 1–2 件上衣、兜帽或主要道具；黑色用于头发、裤子和线稿。禁止把整页染黄，也禁止蓝紫渐变、彩虹服装和多色背景。
- 浅色纸面是画面主体。十张参考图的浅色区域约占 65%–86%；正式配方要求大面积安静留白，主体通常位于中下部。
- 每张图只讲一个动作或一个关系。背景通常为空，最多加入 0–2 个直接参与叙事的道具；可使用一条略歪的地面线、几笔运动线或少量符号。

### 叙事语法

- 核心不是“萌娃头像”，而是用极少动作表达陪伴、照顾、害羞、疲惫、鼓励或小误会。
- 两人关系通过身体距离、牵手、递物、低头、靠肩、追赶等接触动作表达。符号只做补充，不能替代人物动作。
- 允许单格或两格。两格必须共享同一人物和动作因果，分隔线简单，不能扩展成复杂漫画页。

## 固定测试场景

### S1：参考图同构、角色原创

一位短卷发姐姐蹲下，帮弟弟系松开的鞋带；弟弟低头站着，手里握一只暖黄色纸风车。两人穿不同剪裁的衣服，不穿兜帽，不复用参考图的人物、发型、服装或站位。竖版，主体位于中下部，背景为空，脚下只有一条略歪的黑色地面线。

### S2：跨主体

一只瘦长的小狐狸踮脚，把一艘暖黄色纸船放进浅浅的水洼。狐狸保留本画风的圆方头、小点眼、短线嘴和极简四肢；尾巴只是一条松弛弧线。画面只出现狐狸、纸船和一小段铅灰色水痕。竖版，大面积暖白留白。

## 验收维度

每项 0–5 分。候选图总分至少 32/40，且不能触发硬失败条件。

1. 形体语法：圆方头、短粗身体、极简手脚，动作清楚但不做三维 Q 版。
2. 五官语法：小点眼、短线嘴、低压腮红，情绪主要来自动作和倾斜。
3. 线材语法：轮廓有真实压力变化、断续和轻微回描，不是矢量描边。
4. 黑色笔触：头发和裤子保留方向性干笔轨迹与白色断缝。
5. 黄色材质：暖芥末黄低饱和、轻微不均匀，不荧光、不塑料。
6. 构图：暖白负空间占主导，背景和道具受控。
7. 叙事：单一动作和人物关系一眼可懂，符号不喧宾夺主。
8. 原创边界：没有复用原人物、固定服装、原构图、水印或文案。

## 硬失败条件

- 出现参考图水印、账号名、作者名、原文案或近似原图布局。
- 复用“相同黄兜帽双人组合”或其他可识别固定角色设定。
- 变成商业矢量、主流萌系绘本、3D、公仔、动漫大眼或写实儿童。
- 轮廓统一粗黑，头发和裤子变成无笔触的纯黑块，或全画套同一种数字噪点。
- 黄色高饱和荧光，或新增蓝、紫等大面积主色。
- 背景填满、完整室内或风景透视，或出现超过 2 件背景道具。
- 只保留“可爱黄衣孩子”，却丢失暖白留白、干性墨线和动作叙事。

## 截至 2026-08-24 的公开资料结论

- [OpenAI GPT Image 2 模型页](https://developers.openai.com/api/docs/models/gpt-image-2)显示该模型支持高保真图片输入，并提供 `gpt-image-2-2026-04-21` 快照。正式调用包记录这个快照，不只写浮动别名。
- [Midjourney Style Reference 官方文档](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference)把画风参考定义为迁移颜色、媒材、纹理和光线，而不是复制人物或物体；这与本项目“画风锚点只约束视觉语言”的边界一致。
- [Adobe Firefly 构图参考文档](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/match-image-composition-to-reference-image.html)把构图参考拆成轮廓与深度，并提供强度控制；[Photoshop 参考图文档](https://helpx.adobe.com/photoshop/desktop/create-open-import-images/create-images/use-reference-images-for-consistent-results.html)又把参考范围拆成单一物体或整张场景。可迁移的工程结论是：画风、角色和构图需要使用不同参考角色，不能把一张图同时当三种真源。

## 当前验收结论

工程回归和用户视觉验收均已通过：v3 原创锚点、三次同提示词人物回归和人加狗跨主体场景均达到新的 34/40 门槛；用户于 2026-08-24 明确回复“通过”。渲染器强制 v3 锚点像素校验、模型快照、直接生成、主体内容锁和最终机读验收；失败候选整张拒收并重新生成。验证器即使收到满分人工评分，也会拒绝纯白空图、候选 SHA-256 不匹配、预期主体与实际主体不一致、身份替换或必要物件丢失的候选。随机模型仍不承诺逐像素一致；本项目所说的稳定，是核心画风变量通过固定锚点和验收协议保持，偏离协议的结果不进入交付。
