# 风格 21 灯下独白彩铅:研发与验证记录

状态:`accepted-engineering`,待用户视觉验收。日期:2026-09-04。

## 目标和边界

用户提供一张外部参考图(暖灰纸面、彩铅路灯、小女孩仰望、灯下手写中文、右下红色印章),要求拆解画风并让 Codex 内置生图达到"给一段文字直接出图"。红色印章按要求不处理。

参考图只用于观察和维护者验证,不保存进仓库,不作为公开资产分发。配方、默认人物、文案样例均为本轮新写;不复现原图印章、作者名或账号。

生成模型有随机性,本项目不承诺逐像素一致。这里说的稳定,是指同一配方在重复生成和跨场景生成中都保持核心画风变量,偏离的结果可以按硬失败项拒收。

## 参考图机制拆解

| 维度 | 参考图观察 | 配方对应段 |
|---|---|---|
| 纸面 | 整张是暖灰米色图画纸,纤维斑驳纹全画可见;四角偏冷灰,灯下偏暖 | PAPER |
| 媒材 | 石墨与彩铅,线细而微抖,着色干而颗粒化,纸色透出 | MEDIUM |
| 密度 | 极稀疏:灯柱几根线,地面只有一排路沿石,其余留空 | SPARSENESS |
| 光 | 灯笼是唯一光源;暖黄光晕覆盖文案区,向下渐隐;灯柱和人物各一条长投影从灯脚放射 | LIGHT |
| 构图 | 灯柱在中偏左、约占画高 55–60%;人物极小(不到灯柱四分之一)站在灯脚仰望;路沿石斜穿下三分之一,左高右低;留白超过六成 | SCALE、COMPOSITION |
| 色板 | 暖灰纸、石墨灰、暖黄、灰粉花与丝带、灰绿叶、灰蓝裙;无纯黑、纯白、荧光色 | PALETTE |
| 文字 | 中粗黑笔手写楷体,居中排在灯右侧光晕里,一行一句,末行省略号 | TEXT |
| 装饰 | 细藤蔓带粉色五瓣小花和一条粉丝带缠绕灯柱 | 默认主体 |

## 固定测试场景

- S1 参考同构:默认招牌场景 + 参考图原文案(6 行)。
- S2 同构换文案:默认招牌场景 + 4 行新文案。
- S3 跨场景:老人坐长椅、脚边一只猫,3 行文案。
- S4 长文案:默认招牌场景 + 8 行文案。
- S5 跨场景:撑伞的长发年轻女子,3 行文案。

## 判定维度(每项 0–5,总分 30;入库门槛 26 且无硬失败)

1. 暖灰纸面与纤维纹。2. 单光源光晕与放射投影。3. 稀疏度(无鹅卵石场、无密排线、无装饰铁艺)。4. 人物尺度(不到灯柱四分之一)。5. 中文文案逐字准确、手写楷体、位置在灯右光晕内。6. 低饱和限色。

硬失败:文案任一字错漏;白纸或彩色背景;鹅卵石铺满、建筑树木星月;人物超过灯柱四分之一;出现印章、签名、水印、多余文字。

## 轮次记录

### 第一轮 `prompt-v1-base.txt`(r1/)

三张的纸面、灯光方向、藤蔓丝带和文案全部正确;中文 3/3 逐字准确。稳定偏差两项:画得过满(密排线、整片鹅卵石地面、装饰铁艺)和人物过大(s2 女孩接近灯柱一半高)。评分 s1 22、s2 19、s3 20,均未通过。

### 第二轮 `prompt-v2-sparse-and-scale.txt`(r2/)

只针对两项偏差新增 SPARSENESS 和 SCALE 段,并把文案笔画改为中粗黑笔。三张全部达标:s1 29、s2 29、s3 28。s3 输出 1024×1536(2:3),归一化后使用。

调用层问题两项,已记录在案:codex 进程继承 stdin 时会挂起等待输入,必须 `</dev/null`;codex 在仓库内运行会读取 AGENTS.md 的"不要生图"规则并拒绝一次,提示词首句需声明维护者验证例外(或在仓库外目录运行,封装脚本采用后者)。

### 第三轮 同配方稳定性(r3/)

- S1 同提示词独立重复三次:29、28、29。构图、尺度、光晕、路沿石、文案全部一致;唯一漂移是末行省略号一次画成 5 个点。
- S4 8 行文案:29,逐字准确,文案块仍在光晕内。
- S5 撑伞女子:29,人物换主体后骨架和媒材不变。

### 封装脚本端到端

`scripts/generate_monologue_card_with_codex.sh` 以单段落无换行文案调用,渲染器自动断句,codex 在仓库外临时目录出图,去元数据并归一到 1086×1448;结果见本目录 `e2e/`。
