状态:`accepted-engineering`,待用户视觉验收。日期:2026-09-04。

## 目标和边界

用户提供第二张外部参考图(与 #21 同一系列:暖白纸、彩铅、上方手写文案、下方背影女子搂橘猫坐在石阶上、两侧红苞小树、右侧红色印章),要求同样达到"给一段文字直接出图"。红色印章按要求不处理。

参考图只用于观察和维护者验证,不保存进仓库,不作为公开资产分发。配方、默认人物、文案样例均为本轮新写;不复现原图印章、作者名或账号。

与 #21 的关系:两者共用"手写独白 + 彩铅小景"骨架和同一套文案处理规则,渲染器与封装脚本按 `MONOLOGUE_STYLE_IDS` 共用;区别在纸色(灰 / 暖白)、光线(路灯夜景 / 日景)、版式(文案在灯右 / 文案在上方)和招牌场景。

## 固定测试场景

- S1 参考同构:默认招牌场景 + 参考图原文案(7 行 + 分段空行)。
- S2 同构换文案:默认招牌场景 + 4 行带分段的新文案。
- S3 跨场景:男孩和小狗,3 行文案。
- S4 跨场景:老人和小女孩靠坐,4 行文案。

## 判定维度(每项 0–5,总分 30;入库门槛 26 且无硬失败)

1. 暖白纸面、纸纹弱于笔触。2. 上文下图版式与中间空纸。3. 背影坐姿与同伴接触。4. 窄石阶、浅排线、通宽平台线。5. 树苗稀疏、红苞少。6. 中文文案逐字准确、居中、分段空行保留。

硬失败:文案任一字错漏;灰纸或彩色背景;天空、远景、建筑、茂密花丛、宽重石阶;人物正面或站立;整图漩涡或浮雕数字纹理;印章、签名、水印、多余文字。

## 轮次记录

### 第一轮 `prompt-v1-base.txt`(r1/)

文案 3/3 逐字准确,分段空行保留。稳定偏差:灌木画成茂密花丛(s1、s2),石阶过宽过重且排线过密(s1、s2),s2 整图出现漩涡状数字纹理。评分 s1 22、s2 18(硬失败)、s3 25。

### 第二轮 `prompt-v2-sparse-saplings-narrow-steps.txt`(r2/)

改树苗定义、石阶宽度与通宽平台线、浅排线,并在 AVOID 加入漩涡纹理。三张全部达标:s1 29、s2 29、s3 29。

### 第三轮 v2 同提示词重复(r3/)

重复 a、b 达标(29、29);重复 c 与跨场景 s4 整图出现漩涡浮雕纹理,判硬失败。四张中两张失败,说明 v2 的 AVOID 不足以压住这项漂移。根因判断:PAPER 段"像拍摄的纤维纸、纹理清楚可见"把浅色纸推向浮雕纹理,MEDIUM 段"方向性笔触"被解释为圈状涂抹。

### 第四轮 `prompt-v3-flat-grain-no-swirl.txt`(r4/)

只改两处:纸纹改为"细密均匀、只隐约可见、明显弱于铅笔线,不得成为斑驳、浮雕、大理石、指纹或漩涡纹";彩铅笔触改为"短直或微弯的方向性排线,不得是圈、涂抹漩涡或螺纹",并把禁纹理范围扩到石阶。重复 a、b、c 与跨场景 s4 均无纹理漂移:29、29、27、29。剩余轻微漂移:重复 c 文案左对齐、省略号 5 点、输出 2:3。
